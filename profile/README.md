# Good Heart Tech

Good Heart Tech is a volunteer-run nonprofit providing free IT and cybersecurity services to other nonprofits in the Boise area.

- Website: https://goodhearttech.org- Contact: tools@goodhearttech.org

We work like an MSP: our volunteer engineers are IT and security professionals who donate their time to keep local nonprofits safe and running.
