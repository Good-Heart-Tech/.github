# Security Policy

Good Heart Tech takes security seriously, both in our own systems and in the work we do for the nonprofits we support.

## Reporting a Vulnerability

If you discover a security vulnerability in any of our repositories or services, please report it privately rather than opening a public issue.

- Email: tools@goodhearttech.org
- Include a description of the issue, steps to reproduce, and any relevant logs or screenshots.

We will acknowledge your report as soon as possible and work with you to understand and address the issue.
